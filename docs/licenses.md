  - 표는 손으로 적지 않습니다. `[[라이선스 표]]` 자리에 빌드가 실제 설치된 패키지로

  - 목록은 package.json의 dependencies에서 하위 의존성까지 모두 따라가고, service
    worker에 들어가는 workbox 런타임도 더합니다. 타입 선언(@types/*)은 빼고, 빌드 도구는
    배포물에 코드가 실리지 않으므로 뺍니다.
  - 빌드는 번들에 실린 모듈이 모두 목록에 있는지 확인하고, 빠진 것이 있으면 멈춥니다.
  - 패키지에 라이선스 파일이 없으면(글꼴 pretendard) 원문을 public/licenses/에 두고
    thirdPartyLicenses.ts의 BUNDLED_LICENSE_FILES에 적습니다.
  - 생성 원문 파일명은 원문의 SHA-256 해시를 씁니다. 같은 패키지의 버전별 원문이
    달라도 충돌하지 않으며, 글꼴처럼 저장소에 둔 원문의 경로는 유지합니다.
  - licenseInventory.ts가 표·원문·번들 검증용 수집 결과를 공유합니다. 관련 요청에서
    package.json, 잠금 파일, 실제 패키지와 원문의 파일 상태를 확인해 변경 시 갱신합니다.
    일반 앱 요청은 수집을 건너뛰고, 빌드가 시작되면 스냅샷을 초기화합니다.
